# HyunDPCR 제품 전략 v1.0

**작성일:** 2026-11-13 · **상태:** 전략 가설(시장·의학·규제 검증 전) · **대상:** 창업자, 임상연구 파트너, 개발팀

## 1. 한 문장 전략

**HyunDPCR = 위험 점수 계산기를 넘어서, 시간에 따른 암 진단 위험·진단 경로·검사의 정보 가치를 비교하는 연구용 의사결정 인텔리전스 플랫폼.**

- **프로젝트명:** HyunDPCR
- **영문 확장형:** Dynamic Pan-Cancer Risk & Diagnostic Decision Intelligence
- **주 제품 사용자(초기):** 대학병원 역학·의료정보학 연구자, 조기진단 연구팀
- **구매자(가설):** 연구책임자/연구실, 병원 연구부서, 연구사업 수행기관
- **초기 판매물:** 분석 워크벤치, 재현 가능한 시뮬레이션, 감사 가능한 보고서, 고객 데이터 기반 현장 평가
- **중장기 제품:** 임상적으로 검증되고 규제 요건을 충족한 경우에만 의사결정 지원(CDS) 통합

## 2. 해결할 문제와 JTBD

비특이적 증상(예: 피로, 체중변화, 복통 등)의 첫 진료 후에는 증상의 지속·재진·새 검사결과가 수집된다. 고정된 시점의 단일 점수만으로는 **언제 위험이 변했는지, 다음 평가가 어떤 정보를 가져오는지, 대기시간과 검사 역량이 경로에 어떤 영향을 미치는지** 연구하기 어렵다.

**Research JTBD:** “우리가 정의한 환자 코호트에서 새 임상 증거가 들어올 때 위험과 불확실성이 어떻게 변하며, 의학적으로 허용되는 정책 대안이 진단 경로에 미치는 영향을 재현 가능하게 비교하고 싶다.”

**현장 구매 가설:** 기존 도구/논문이 제공하지 않는 복합 시계열 시뮬레이션과 감사 로그를 한 작업공간에서 제공하면 연구 재현성·분석 시간을 개선할 수 있다. 이는 인터뷰와 유료 파일럿으로 검증해야 한다.

## 3. 범위: 좁게 시작해 넓게 확장

- **첫 문제:** 성인 1차의료의 비특이적 증상 진료 후 **정해진 기간 내 암 진단 기록** 예측 및 진단 경로 비교.
- **위험 산출 기간:** 90/180/365일(연구별 사전 정의; 하나의 비교 기준을 선택).
- **암종:** 전체 암종의 합산 위험 및 표본수가 충분한 암종별 보조 분석. 희귀 암종은 불확실성을 표시하거나 산출 제한.
- **첫 데이터:** 가상 환자 시계열. 실제 환자 분석은 법적 근거·기관 윤리·데이터 접근 승인을 확보한 후.
- **분리:** 소아 두통 및 뇌종양의 진단 지연 연구는 방법론적 영감이지만 초기 범암종 제품의 데이터·성능 근거가 아님.
- **용어:** 암 '발생'과 '진단'은 다르고, 진단 지연과 종양 '진행'은 다름. 추정 목표를 UI/API에서 구분.

## 4. 차별화 포지셔닝(검증해야 할 가설)

| 기존 접근 | 이미 가능한 것 | HyunDPCR 후보 차별화 |
|---|---|---|
| 정적 증상 기반 위험도 | QCancer는 다양한 암종의 현재 미진단 암 위험 및 장기 위험 추정 | 관찰 시점마다 업데이트된 위험·근거 이력, 불확실성 변동 |
| AI 암 의심/의뢰 지원 | C the Signs는 조기 발견·임상 의사결정 지원 | 환자별 **허용 가능한** 추가 정보 전략의 분석/비교 |
| 혈액검사 기반 위험 층화 | PinPoint는 일상 혈액 검사로 의심암 의뢰 환자 위험 분석 | 증상·재진·검사·의뢰를 함께 반영한 동적 경로 시뮬레이션 |
| 종단 EHR 기반 예측 연구 | 2026 TrajOnco는 15개 암종의 종단 EHR 위험을 연구 | 명시적 검사 정보가치·업무 용량·하방 위험 결합 검증 |

**금융공학 이름만 붙이는 것은 해자가 아님.** QCancer 자체도 경쟁위험 방법을 사용한다. 의료 분야에 가치정보 분석·결정곡선 분석도 기존 방법으로 존재한다. 새로움은 개별 기법의 '최초 사용'이 아니라 **임상적으로 허용되는 행동집합, 시간 갱신, 불확실성, 자원 제약, 감사성**을 통합해 검증할 수 있는지에 달려 있다.

## 5. 모듈 설계

1. **Signal** — 시간 갱신 위험, 확률 보정, 불확실성, 각 진료 이벤트의 기여도.
2. **Options** — 가정에 근거한 검사/재평가 전략의 정보 가치와 기대 손실 비교; 의료진 의사결정의 대체가 아님.
3. **Pathway** — 최초 진료→검사→의뢰→확진/비진단/추적종료 상태전이 및 가상 대기열.
4. **Guard** — 모델/데이터 버전, 시나리오 가정, 집단별 오류, 안전 경계, 내보내기 감사 로그.

**우선순위:** Signal + Guard 최소형 → Pathway → Options의 연구용 모의실험 → 임상 검증 후 확장.

## 6. 비즈니스 모델과 가격 가설

- **시장 1: 연구기관 (B2B Research SaaS/온프레미스).** 연구별 라이선스, 분석 서비스 또는 제한된 기간의 유료 파일럿. 재현성·보안·공동 연구용 기능이 판매 근거.
- **시장 2: 병원 운영·혁신팀.** 검사의 대기열과 의뢰 경로를 가상 비교하는 시뮬레이터. 환자 의뢰 자동화는 판매 범위 밖.
- **시장 3: EMR / 디지털헬스 벤더.** 외부 검증 및 규제·계약을 충족한 뒤 API/기관 라이선스.
- **가격:** 현재 증거 없음. 가격표를 추정 사실처럼 제시하지 않으며 인터뷰에서 지불의사·조달 절차·데이터 연동 비용 확인.
- **비용 구조:** 데이터 이용·보관, IRB/법무/보안, 모델 개발·검증, 의학 자문, 임상 연구, 고객 연동, 인증, 보험.

## 7. 제품/상업 가설 및 중단 기준

| 가설 | 검증 방법 | 제안 게이트(목표치, 현재 실적 아님) |
|---|---|---|
| 연구팀에 분명한 업무 고통이 있다 | 12–15건 구조화 인터뷰 | ≥8건에서 명시적 반복 과제·예산 주체 확인 |
| 독자적 workflow value가 있다 | 기성 도구 대비 블라인드 작업 시간/재현성 비교 | 하나 이상의 작업에서 실질적 개선 입증 |
| 금융공학 확장이 의사결정에 가치 있다 | 동등 정보의 baseline + DCA + 의학적 검토 | 성능/순편익 개선이 없으면 기능 제거 |
| 실제 데이터 확보가 가능하다 | DUA/IRB/데이터 사전·정의 협의 | 재현 가능한 연구 코호트 및 적법한 접근 확보 |
| 구매자와 사용자가 일치하거나 연계된다 | 유료 파일럿/LOI | 최소 1개 유료 시범 또는 구매 조건 구체화 |

## 8. 절대 주장하지 않을 것

- “이미 조기진단 정확도를 높였다”, “진단 지연을 줄인다”, “모든 암을 예측한다”.
- “검사를 기다려도 안전하다”, “개인의 암 위험은 2.1%다” (가상 데모 수치).
- “금융공학 기반이므로 의학적 정확도가 높다”.
- “FDA/NICE/식약처 인증 완료” 또는 “의료기기 아님” (사용 목적 판단 전).

## 9. 실행 제안

첫 8~12주에는 모든 암에 걸친 고성능 딥러닝 대신 **재현 가능한 합성 데이터와 단순 기준선(로지스틱/이산시간 생존모형)**으로 위험 변화·경로 변화의 기획 가치를 보여준다. 실제 데이터 접근과 임상 자문이 확보되어야 예측 유효성과 검사의 가치 분석을 주장할 수 있다.
