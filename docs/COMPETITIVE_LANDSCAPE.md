# 경쟁 제품·근거 레지스터 v1.0

**검색·정리 기준일:** 2026-11-13. 공식 제품 페이지·학술 논문 중심. 제품의 기능·성능·가격·배포 범위는 변경 가능하므로 후속 검증 필요.

**결론:** '다중 암종', '시계열', 'AI', '경쟁위험'만으로는 차별화 부족. **투명한 decision-analytic workflow + 재현성 + 데이터/모델 감사 기능**을 제품 수준으로 통합하고 기존 표준과 비교 평가해야 한다.

## 2. 기술 자체의 선행성

- **경쟁위험 모델:** 이미 QCancer에서 사용. 금융공학에서 이름을 빌려왔다고 새로운 방법은 아니다.
- **Value of Information / Decision-curve analysis:** 의료 의사결정 분석에서 선행 연구가 있다. 임상적 손익을 자체 임의 점수로 포장하면 안 됨. [Vickers et al. 2016](https://doi.org/10.1136/bmj.i6).
- **종단 EHR 위험 추정:** TrajOnco(2026) 등 선행연구가 있다. 독창성은 기존보다 높은 성능을 실증하거나 새 업무 가치를 입증해야 확보된다.

## 3. 비교 실험 원칙

- **같은 데이터·대상군·예측 시점·결과 정의·추적 기간**을 유지하는 경우에만 예측 모델끼리 비교.
- QCancer 알고리즘 접근/라이선스가 허용되는지 먼저 확인. 미허가 코드 복제 금지.
- 단순 기준선: 연령·성별·증상 + 로지스틱/이산시간 생존, Cox/Fine-Gray 또는 적절한 경쟁위험 기준선.
- 타 모델의 논문상 AUROC를 HyunDPCR의 성능 목표나 우월성 근거로 사용 금지.
- 비교축: 보정, 판별, 순편익, 행동가능성, 작업 시간, 재현성, 데이터 입력 부담, 오류율, 사용성.
- 외부 제품 기능 부재 여부를 추측으로 단정하지 않고 **'공개 자료상 확인되지 않음'**으로 표시.

## 5. 추가 조사의 우선순위

1. 경쟁사 제품 데모/계약 범위: 비용·실제 사용자·일부 기능 공개 자료의 한계 확인.
2. 최소 3개 병원/연구팀의 진단 의사결정 흐름 관찰(필요한 경우 윤리·접근 승인).
3. 대상 국가별 데이터 접근법, 검증 인프라, 구매 절차 확인.
4. '디지털 PCR(dPCR)'과 혼동되지 않는 상표/검색엔진 전략 검토.
5. 기존 연구의 정보가치/순편익 접근을 문헌으로 체계화하여 신규성과 경계 설정.
